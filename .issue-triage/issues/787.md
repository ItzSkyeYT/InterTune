# #787 — Scrollbar flickering / jumping / skipping

**What goes wrong:** Scrollbar thumb jumps around or its size rapidly changes when scrolling
lists that aren't at minimal scrollbar size. Purely visual, functionality unaffected.

**Where it lives:** `app/src/main/java/com/dd3boh/outertune/ui/component/ScrollBar.kt:18-19`
wraps `InternalLazyColumnScrollbar` / `InternalLazyVerticalGridScrollbar` from the external
Gradle dependency `com.github.nanihadesuka:LazyColumnScrollbar` (declared in
`gradle/libs.versions.toml:45`). The wrapper file already carries a comment citing the exact
upstream bug: `https://github.com/nanihadesuka/LazyColumnScrollbar/issues/40`.

**Evidence:** Confirmed + repro steps in the issue; reporter references the same upstream
issue. No stack trace (it's a visual glitch, not a crash).

**What a fix would involve:** Either wait for/patch upstream `nanihadesuka/LazyColumnScrollbar`,
or vendor a local fork of the library with a patch — both out of scope for this routine
(root cause confirmed to live in a third-party library, and vendoring would mean editing
dependency versions / adding a new build dependency, which is forbidden).

**Why not fixed this run:** Root cause is in a third-party library dependency, not in
InterTune's own code. This is a hard-abort condition (Phase 2 rules: "root cause is in a
submodule or third-party library").

**What would raise the score:** Nothing — this needs an upstream library fix or a
maintainer decision to vendor/patch the dependency, which is a decision beyond a routine
triage fix.

**State:** not-applicable (upstream library bug, confirmed via existing code comment)
